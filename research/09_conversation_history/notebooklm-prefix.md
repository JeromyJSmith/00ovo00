How do ternary weights improve CPU-based LLM inference performance?

Ternary weights—which restrict model parameters to just three discrete values {-1, 0, +1}—radically improve CPU-based LLM inference by eliminating heavy arithmetic, slashing memory requirements, and unlocking specialized software optimizations.

2. Alleviating the Memory Bandwidth Bottleneck CPU inference for large models is almost entirely bottlenecked by memory bandwidth rather than raw compute capability
