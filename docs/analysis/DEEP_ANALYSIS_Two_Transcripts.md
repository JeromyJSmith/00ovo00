## SECTION IV: THE INFORMATION CASCADE PROBLEM
### When Crowds Become Delusional (Lorenz et al., 2011)

#### The Three Destructive Phenomena

**1. Social Influence Effect**
- Diversity collapses WITHOUT accuracy improvement
- People conform for conformity's sake (not truth-seeking)
- Visible but invisible: "Everyone else thinks X, so I'll think X"
- *Lexicon:* "Herding," "pluralistic ignorance," "false consensus"
- **Crisis:** This is Twitter/Reddit/Facebook by design

**2. Range Reduction Effect**
- Complex truths live at outer edges of initial guesses
- When people see others' estimates → timidity, clustering toward middle
- **Mathematical consequence:** True answer pushed OUTSIDE the range of all guesses
- Example: If truth is 7, but everyone clusters 4-5, system can never converge correctly
- *Lexicon:* "Conservative bias," "risk-aversion cascade," "truth-erasure"
- **Crisis:** Binary prediction markets force this collapse

**3. Confidence Effect** (Most Terrifying)
- As estimates artificially converge → individual confidence INCREASES
- **Perverse outcome:** Getting progressively MORE WRONG while FEELING more RIGHT
- Synchronized delusional consensus (see: Iraq War WMD intelligence)
- *Lexicon:* "False confidence," "correlated delusion," "collective hallucination"

#### 2025 Orset Chowsky Study (Machine Learning Parallel)
- If AI models trained on same biased data → larger ensemble = stronger error
- **Scaling principle:** Correlated ignorance amplifies with scale
- **Lesson:** Homogeneous data feeds destroy collective intelligence
