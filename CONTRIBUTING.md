# Contributing to Global Rome

Welcome. This is a memorial and research project honoring Rome Viharo's work on collective intelligence and ternary logic.

## For Researchers

Contribute to `research/` with literature, citations, methodology, and interdisciplinary connections.

- Create folders for new research areas (e.g., `research/16_new_topic/`)
- Use markdown for all documents
- Link related documents with explicit references
- Include citation metadata at the top of substantial pieces

## For Developers

Contribute to `app/` (Next.js application) and `global-ohm/` (implementation).

- Follow Next.js App Router conventions
- Use TypeScript
- Maintain the component structure: `/components`, `/lib`, `/app`
- Test locally before submitting: `npm run dev` in `global-ohm/`
- Reference the tech stack in CLAUDE.md

## For Writers

Contribute to `docs/` with explanations, clarifications, and accessible summaries.

- Target plain-language explanations for non-technical readers
- Add to appropriate subfolder (concepts/, analysis/, media/)
- Link to source materials in discovery/ and research/
- Keep summaries concise; reference full documents for depth

## Filing Issues

Use GitHub issues for bugs, feature requests, and questions. Include:
- What you observed
- What you expected
- Steps to reproduce (if applicable)
- Relevant file paths or links

## Pull Request Conventions

- One focused change per PR
- Write a clear title and description
- Reference any related issues
- Keep commits atomic and well-messaged

## Code Style

- **Styling:** Tailwind CSS with minimal custom CSS
- **Naming:** camelCase for variables/functions, PascalCase for React components
- **Comments:** Document the "why," not the "what"
- **Linting:** Run `npm run lint` before submitting
